Shopify has no abandoned-checkout webhook, so Briyo OS polls Shopify instead. Once connected it pulls automatically; use this button when you don't want to wait for the next run. Carts pulled this way carry a working recovery link, which the CSV export does not.

Shopify's export carries no recovery link, so the Cart link button will be empty on imported rows — callers can still phone and WhatsApp. Shopify also has no equivalent of GoKwik's drop stage or RTO risk flag, so those stay blank rather than being invented.
